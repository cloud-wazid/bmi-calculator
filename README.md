# ⚖️ BMI Calculator

A simple BMI (Body Mass Index) calculator that takes weight and height as input and returns the BMI value along with the health category (Underweight, Normal, Overweight, Obese).

## Features
- Calculates BMI from weight (kg) and height (cm)
- Displays health category with color-coded result
- Input validation for invalid entries

## Tech Stack
- HTML
- CSS
- JavaScript (Vanilla, no frameworks)

## How to Run
1. Clone this repository
2. Open `index.html` in any web browser
3. Enter your weight and height, then click "Calculate BMI"
